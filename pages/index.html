Nintendo DS / DSi

Mega Man X4

Gere o arquivo .nds da beta 9 com seu dump USA SLUS-00561.

Compilar na sua máquina

Use Linux x86-64 ou WSL no Windows, com Python 3.11+, Git, GCC, Make e Tar. A primeira compilação baixa o SDK e as dependências.

Execute no terminal do Linux ou WSL:

git clone https://github.com/Lawtrel/megamanx4-dsi-port.git
cd megamanx4-dsi-port
python3 tools/serve_builder.py

Com o terminal aberto, selecione o .bin no compilador local. O navegador baixa o .nds quando o processo termina. O dump fica no seu computador.

Abrir compilador local

Testar o jogo
